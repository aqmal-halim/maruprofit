# Ticker Sector Composite Factor fingerprint Signal Tilt
How to read it. Composite = weighted blend of the four factor scores, ranked within each sector (so it stays near the index). Fingerprint shows why a name ranks — which factors are strong (teal) or weak (clay). Tilt = suggested over/underweight vs an equal sector baseline.
Data & limits. Sample data is illustrative only. Live mode needs your own free API key; free tiers are rate-limited, so keep your list short. Value/Quality reflect current fundamentals; momentum/low-vol use recent prices.
